# 如何计算现值

要回答这个问题，我们先聊聊金钱的时间价值：现在的100块钱和1年后的100块钱，大家觉得是一样的吗？

答案是不一样，因为现在的100元，投资一年期国债可以获得无风险收益率，比如当前一年期国债利率是1.54%，一年后可以获得101.54，也是就是说现在的100相当于一年后的101.54。

反过来一年后的100，现在值多少钱叫做现值，其计算方法是100除于无风险收益率：

![](https://mmbiz.qpic.cn/mmbiz_png/YHQYfznBE4dp6GNfpVY4TQtvKiaIN33PPkVBlCxI39F9SILmBKn2POEST64YaibrKIG3FaqqxuB6Y5lVNF4EEkjw/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=3)

也是就是说一年后的100相当于现在的98.48，所以借钱的兄弟姐妹们，以后记得算账。

这个就叫做贴现率，用于计算未来的钱现在值多少，通常贴现率 = 无风险收益率 = 当前国债利率

这也是非常重要的一种估值方法，不管我们是投资股票还是债券，本质都是为了赚取未来的现金流。

我们愿意花多少钱购买这个资产，取决于它未来能产生多少现金流，然后把这些现金流折现到现值就知道它值多少钱，我们应该出什么价格购买。

# 如何计算债券的现值？

我们举一个例子，假设有两个债券，一个1年期，一个3年期，我们分别计算它的现值，为了简单，假设贴现率都是当下的十年期国债收益率2.2%。

1年前国债现价100元，假设利息是1%，一年后得到的钱是101，那么其现值是：

![](https://mmbiz.qpic.cn/mmbiz_png/YHQYfznBE4dp6GNfpVY4TQtvKiaIN33PPibudiaprvgRnO0yPf9FmBXztPEnMYEF1y0OxQuGeaUe8bPwUFRPcdhLg/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=4)

3年期国债现价100元，假设利息2%，第一年获得利息2元，第二年获得利息2，第三年连本带息归还102，那么其现值是：

![](https://mmbiz.qpic.cn/mmbiz_png/YHQYfznBE4dp6GNfpVY4TQtvKiaIN33PPfpv2BBmQHKXzbr1dolicEia4Kq7hcOLBO7YWVjudxiapIplRQAFqoQtVA/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=5)

**假设现在因为利率上涨，十年前国债收益率涨到3%了**

那么1年期国债的现值是：

![](https://mmbiz.qpic.cn/mmbiz_png/YHQYfznBE4dp6GNfpVY4TQtvKiaIN33PPJhwnurMLmqcPg21picj3zRsesiaIbzGw3ia5dMMu6iag15dx7qgOVbak3Q/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=6)

3年期国债的现值是：

![](https://mmbiz.qpic.cn/mmbiz_png/YHQYfznBE4dp6GNfpVY4TQtvKiaIN33PP7PlBdZflJM0bZ5ficRxBfkbMzJv1Kz3s2kUBF6zg1cQ212mATSNNWtw/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=7)

**1年期国债下跌 (98.83-98.06)/98.83 = 0.78%**

**3年期国债下跌 (99.43-97.17)/99.43 = 2.3%**

**从上面的跌幅可以看到，长期国债受利率影响是更大的。**

当然这个是简单的计算，实际中还需要考虑通胀因素，会复杂一些，但基本的原理是一样的。
