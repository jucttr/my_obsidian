# 5个投资skill， 这是我最新的工作台.....


大家好，我是海榕君。

前两年，有一个投资水平很高的朋友
，提出一个问题，一个公司的价值到底值多少钱？到底怎么应该估值？

很多投资者交流后，最后得出的一个结论：

如果发现你持有的企业市值，小于
未来
**10年权益自由现金流之和 - 权益有息负债
，那么恭喜你，你找到的预期差。**

**但在我实际交易中，我发现只有很少的企业，可以直接推算自由现金流，只有像一些水电、公共事业股、矿产这种类似企业，自由现金流更容易推算。**

**......**

**我给出的方法是，
看10年未来现金流太难了，
分析行业处的阶段相对容易，
然后对不同类型的公司进行估值。**

**![](https://mmbiz.qpic.cn/sz_mmbiz_png/CD0Ziab37FHB7jK9HD5pqbCfK8KvicodhOLZORlFaluZJkZe11L6NClVQVuSTU6Fib2bS42tvmI9AfSzNC7gkw7ibF1ovOphrvpzpdrLbmURkho/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)**

**1. 初创期和导入期的公司，主要是看商业模式是否可行，产业趋势是否跑通。**

**2. 渗透率高速成长期公司，抓住渗透率从5%到40%阶段，戴维斯双击，估值可以适当容忍，进入王鹏的投资框架。**

**3. 爆发期后端（供给过剩阶段），投资者应该回避，经常遭遇戴维斯双杀。**

**4. 出清后成长阶段，进入巴菲特的投资框架。**

**5. 进入成熟期后，我分为4种类型行业：①分红收息 ②衰退烟蒂③二次成长 ④周期成长和周期波动。**

衰退烟蒂股，直接按巴菲特的师兄弟施洛斯的交易框架进行交易。

周期成长和周期波动，是大神冯柳的交易框架。

但是怎么确定一个行业，到底处于什么阶段，

Alpha派

![](https://mmbiz.qpic.cn/mmbiz_png/CD0Ziab37FHA2nicuRjL4BUBMvXl3e0PuxYtQP72YM42amJf6V4cXcTugHtzKZSNajvMEX752zqwZZ0pLKLibJPOFkvxgPiaib1DjpInogT0QAXo/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1)

然后，我把巴菲特过去50年的投资，用行业框架进行拆解。

巴菲特的买入几乎全部集中在"出清后成长（胜者为王）"与"成熟期"两大阶段，且共同特征是"低PE/低PB买入 + 高ROE + 护城河已成型"。

表中没有一笔买在"初创导入期"或"爆发成长期"（即渗透率快速拔估值的高估值成长阶段）。 这与我们前几轮的判断完全一致——
巴菲特回避"赢家未定+估值透支"的爆发期，专注"格局已定+估值合理"的确定性阶段。
