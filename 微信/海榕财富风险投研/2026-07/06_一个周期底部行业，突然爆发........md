# 一个周期底部行业，突然爆发.......


大家好，我是海榕君。

A股市场，一直喜欢两类行业。

一是渗透率成长类行业
，2015年的移动互联网，2021年的锂电新能源，2026年 AI硬件。

二是周期底部行业
，2020年10美元的原油，2020的电解铝行业，2025年的锂矿，2025年的化工品。

2020年油价10美元的时候，巴菲特抄底加仓了西方石油，仍然持有至今。

2020的电解铝行业，
沪铝失守12000元，完全成本12705元/吨，国家同时开启了反内卷，现在沪铝2万2
。

2025年锂矿最低跌到7万，大部分锂矿成本在8万左右，由于全球储能爆发，锂矿今年最高涨到20万，带飞一批牛股。

今天，猪肉行业突然爆发
，牧原股份上涨4.82%， 巨星农牧涨停，猪肉行业盘中领涨今天的A股市场。

最近，一公斤的猪肉的价格已经跌至 14-15元/公斤，已接近或低于许多养殖企业的成本线。

A股喜欢提前抢跑拔预期
，很多时候，股价见底的概率要早于基本面的变化。

但猪肉行业，相比2025年的锂矿有两个劣势：

1.  锂矿的总需求是上涨，锂矿的下游是电动车、储能，全球这两个行业仍然在爆发。

猪肉行业，整体需求是萎缩的，现在很多年轻人，选择吃牛肉和鱼虾作为减脂餐。

2. 猪肉行业，背后和地方GDP挂钩，想完全退出产能不容易。

即使有这两个劣势，
但市场还是喜欢周期底部的行业
，这就是A股。

4.
化工股业绩很好
，万华化学
Q2归母净利润约60.82亿至66.82亿元，同比翻倍、环比增长63.6%至79.7%。

化工行业前两年很惨，国内
PPI连续
**37个月**
同比负增长，119个化工品种中26.89%价格分位数在10%以下，60.50%在30%以下。化工股这次业绩提升，不一定是完全油价上涨带动的，更多的是去产能和反内卷。

5.
A股每一次高开，都不会让投资者失望
