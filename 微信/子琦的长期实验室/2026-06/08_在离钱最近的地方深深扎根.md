# 在离钱最近的地方深深扎根


# 一： 带父母走没走完的路

本周带父母来深圳玩了几天，去了香港澳门，其实我们家 1994 年的时候就来过深圳，打算在这边做生意的，但是在深圳这边被偷了几万块钱，然后人也生病了，所以就回到老家了，正好这一次也是想带父母看看之前没有走完的路。

我觉得赚钱的意义，就在于当我想给那些我在乎的人一些好的体验的时候，我不需要考虑钱的问题，这也是幸福感来源之一。

# 二：主流资产开始给机会

大饼这一周跌到了 6 万，我自己做的评分系统也快达到了买入的区间了，从链上数据来看，大概率还是会继续下跌，目前链上长期持有者成本是 4.8 万，如果按照前两轮来看，大概率是会跌破这个价格的，目前也不好说，走一步看一步吧。

同时美股也开始出现回调，crcl 也回到了 200 亿的估值左右，这一轮下来的话，大概率会出现不错的买点了，持有现金的小伙伴终于要等到买入的机会了。

我自己的思考是，本轮大饼依旧会有不错的买入机会，但是具体跌到什么价格我也不知道，所以我才会做一个数据面板出来，这样的话当我真正想买入的话，我可以看数据，而不是根据价格，我做面板的意义也在于，当左右的数据都指向某一个方向的时候，大概率就是买入的时机。

如果想好的小伙伴，等待机会出现执行就好，但是如果没有想好的小伙伴，可以趁着这个机会思考一下，当所有资产的价格都来到相对低位的时候，要买入什么资产是最划算的。

# 三：参加生财的航海家大会

这一次参加生财的 AI 航海家，最大的收获是对知识库的应用，虽然说分享嘉宾都是做电商、获客类的那些业务，但是对于知识库的这套体系来说还是值得学习的，无论是做内容还是做项目，都可以建立自己的知识库，现在最好的选择就是 obsidian，无论是用 codex 或者 Claude + obsidian，都可以调用知识库的资料和让 AI 更加了解自己。

我自己也一直在用 obsidian，但是没有用的如此灵活，这也算是打开了眼界。

很多知识付费我认为最重要的不仅仅是学习知识，如果有某一个功能可以解决一个很痛的痛点，即便花钱多也是很值得的，同时还能认识一些优秀的朋友，我这次也和几个有自己产品的朋友交流了下，更多的体验是打开了眼界。

# 四：和朋友交流的收获

本周还和一位链上套利做的非常好的朋友做了深度的交流，我问了几个赚钱的案例，都非常让我吃惊，在极端事件，比如 FTX 暴雷，或者是 Luna 暴雷，大家都亏很多的时候，反而是人家赚钱最多的时候，我也很好奇为什么能做到如此的程度，经过交流后发现，这位朋友对每一个持仓项目的理解是非常深的，这里说的不是对规则，而是用一种给项目做审计的态度去阅读项目的代码，这个思维有一些震惊到我。

当我们在讨论同一个项目的时候，我发现有很多东西都是我自己不了解的，就比如 Polymarket 的 UMA 投票机制到底是怎么运作的，要质押多少，这种东西对于我这种空投选手其实是没有研究的很细的。

同时还有对链上的敏感性，以及整套的监控系统，让我觉得这位朋友非常专业，链上发生任何事情在一分钟以内基本上他就能知道，由于我对套利不是很了解，所以在问了一些问题后发现这条路也是非常难走的，更多的是开眼界吧。

# 五：关于赚钱的思考

我在参加完生财的航海家会议以后也在思考，为什么同样的努力下，有的人能赚很多钱，有的人赚的钱不多，这些人的差距在哪里？

我目前的体验是，有的人站在离钱最近的地方，就比如对于做小红书也好，电商也好，那些人赚 100 万的话，我觉得也是需要付出很大努力的，但是对于加密、美股、金融类相关的行业，赚钱的难度我认为是要相对简单的，因为这些人站在了离钱最近的地方。

我也思考过，万一我以后真的亏完了，我要去什么行业再翻身，目前我的答案是，一定要站在离钱最近的行业，比如交易、资产发行、融资等等，在离钱最近的地方扎根，这是我目前觉得赚钱相对友好的赛道，金钱的赛道虽然充满了陷阱，但是也充满机会，我相信也是长期来看最容易积累财富的地方。
