# 子琦周报｜2026.2 W3：不要活成别人期待但是自己不喜欢的样子


# 一：行情/项目

目前行情和项目没什么好说的，不上不下，没有什么可以做的事情，如果说关于行情，接下来最重要的就是想好自己这一轮熊市的建仓逻辑，如果说项目的话，最重要的就是抓住预测市场的龙头，也就是 PM。重要的事情不一定很难，花时间精力想好怎么做就可以了。

# 二：AI 的不可逆趋势

这部分我本来是想放在项目里面写的，但是发现放在 AI 的部分里面写更合适，在两个月之前，我一直觉得 Chat gpt 对我生活的影响已经是巨大的了，我现在任何的问题都会跟他交流，无论是投资，人生，人际关系，但是 gpt 更多还是停留在思考，对话的方向。

从我开始研究 PM 的数据开始，我开始大量使用 Claude code，在春节期间，我自己从零开始研究 PM 的套利，从搜索数据，分析数据，查 bug，监控，下单，我觉得这些事情放在以前我是不敢想象的，即便有 chat gpt 我也不敢想象，因为 Chat gpt 更多还是思考层面，除非用 Codex 这种代码工具。

我自己的体验是，AI 解放生产力带来的变革可能不亚于比特币给这个世界带来的变革，这是一个奇点，我个人体验到我们正处在生产力大爆发的前夜。

我还没有去安装 Open claw ，我只是用 Claude code 去做了我想要做的事情，由于我自己身在其中，这种震撼对我来说是非常有冲击力的。现在只要你有一点点耐心，你有想法，你大概率就可以做很多之前自己做不到的事情，我一个没有任何开发经验的人，零程序基础的人都可以现在自己开发一些东西，我相信任何人都可以。

我自己也会思考，接下来的时代什么是更稀缺的，目前我的思考是「好奇心」，就好像我就是很好奇那些 PM 的地址是怎么赚钱的，我虽然也没研究出来，但是我体验到了 AI 的强大，这个冲击力是不亚于赚到钱的，我觉得我切身体验到了未来的可能性，未来的那个画面从模糊不清到我的体验，AI 帮我完成了这一份体验，让我对未来多了一份相信和乐观。

虽然关于落实在赚钱，我还没怎么想好，但我的思考是，好好呵护自己的好奇心，多去探索可能性，也许有一天我做出来一个产品赚钱也说不定，哈哈。

# 三：我想怎么活

我每次回到家以后都会思考这个问题，可能因为家里有老人，我会情不自禁的想象，如果有一天他们去世了，我有多么的伤心，或者是以后父母要在那个城市等等，同时老家的人生样本也非常不一样，我也会好好体验哪种人生是我想要的，哪种是我不想要的。

新年这段期间，我自己在慢慢体验和思考我和我自己的关系，当我把注意力放在自己身上的时候，我发现我看到了很多我自己那些由于没有关注到从而无法命名的情绪，比如没有安全感，焦虑，紧张，大多数时候在这些情绪出现的时候我也没有去好好留意，但是随着我慢慢的观察，我感知到了我的一些人生模式其实是想把这些情绪「消除」掉。

新年期间我也有阅读了一些书和文章，我目前的体验是，处理自己和自己的关系的重要性不亚于处理和别人的关系，我不想从受害者的角度来阐述我的童年或者是之前的经历，但是我的模式确实是被早期经历所影响，我不想一直处于那个「还在体操队的我」的那种状态，我渴望活成自己的喜欢的样子，而不是我应该成为的样子。

同时我也会被很多「应该」所要求，应该早结婚，应该生孩子，应该穿秋裤，应该多喝水，应该不染头发，等等，我曾经被要求「应该」了二十多年，虽然我挺叛逆的，但是我发现我自己很多时候也是情不自禁按照「应该」的方式去活着。

这次过年回到家，我自己也开始慢慢觉察，「我应该」和「我想要」的区别，我不想为了别人，社会压力，别人的期待，甚至是父母的期待活成那个「应该」的样子，即便那个应该是「看起来正常」的。

我现在开始会慢慢问自己，这是我想要的吗？

举个例子，如果我想去旅游，我选择去冰岛，我会开始留意「我是因为别人去了，拍照好看，我也想去装逼然后想获得更多点赞」还是「因为这个地方我没去过，我真的想去看看，我对这个地方好奇」这两个想法之间的区别。一个出发点是期待别人的反馈，另一个出发点是源于自己内心的渴望

我觉得能按照自己内心想要的去活着，我体验到的是幸福，宁静，舒适，而不是活成被社会价值观，亲人，朋友所期待的那个样子。

我很开心和庆幸我自己还能有这样的想法，这可能是叛逆，倔强，但对我来说这也是我自己想好好活着的一种痕迹吧。

最后祝大家都能活成自己想要的样子，聆听自己，爱自己。
