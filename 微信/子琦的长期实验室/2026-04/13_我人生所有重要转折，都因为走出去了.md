# 我人生所有重要转折，都因为走出去了


2026年4月第二周，聊三件事。

# 一、AI折腾两天后的感悟：别把时间花在修工具上

Claude 把龙虾的中转方案封了，我花了整整两天时间修。

修完以后我的感受是：我的时间不应该花在这上面。

工具坏了就换，别死磕。目前我主要还是用 Claude Code，龙虾的依赖没那么强，对工作影响不大。我相信这个功能迟早会被完善，现在不方便是正常的，不可逆的发明早晚会成熟。

核心判断：
顶级模型的体验确实好，但为了用上它而反复折腾，本身就是一种内耗。

# 二、Polymarket 数据研究的新发现

这几天更新了 PM 的全量数据，发现了一个很夸张的事实：

最近一个月的数据量，接近过去半年的一半。

增速在加速。

我自己目前在探索几个方向，主要围绕聪明钱。但有几个问题还没解决：

1. 之前的聪明钱会换地址，历史数据的有效性存疑
2. 要关注的是"未来的聪明钱"，而不是"过去的聪明钱"
3. 如何定义聪明钱——这个问题本身就需要时间

其他方向还在探索，没结果。但反正闲着也是闲着，研究出来是收获，研究不出来也熟悉了 PM 的架构和 Claude Code 的能力，不亏。

最近也认识了几个同样在研究 PM 赚钱路径的朋友，这条路上有人一起走，比一个人闷头搞强太多。

# 三：武夷山之行：看到了不同的人生

本周末去武夷山参加了贝版老师的俱乐部年会，我自己也是分享嘉宾之一，这一趟旅程我觉得收获还是蛮大的。

借着别人的眼睛，打开了一些视野。

具体学到什么内容不展开了——机器人、太空经济、期权玩法，这些回来实践了才有更深的体会。

我想聊的是一个更底层的东西：他验证了我自己一直以来的成长方向是没问题的

我回顾自己人生所有的重要转折，全部都是因为走出去了。

认识了新的人，被带到了一个新的世界。

我再聪明，一个人在家想，也想不出今天的路。不是因为我笨，而是很多可能性，你不见到活人，根本不知道它存在。

走出去真的很重要，看看这个世界发生了什么，别人在做什么，虽然不一定有用，但是可以帮我打开我的眼睛和大脑。

这次有一个触动很大的点——认识了几位来自美国湾区的朋友，和他们交流让我看到了另一种生活方式。不是说国外就好，而是我亲眼看到了：原来人可以这样活。

李笑来说过"看见别人成功很重要"。我补充一句：
看见别人活出不同的样子，比看见别人成功更重要。

因为成功你可能学不来，但"原来可以这么活"这个认知一旦打开，就关不上了。

我很庆幸的是，这个想去外面看看的种子，在我心里至少 15 年了——从体操队开始就有——到今天它还在。我依旧能感受到那种好奇心的冲动。我觉得这是上天给我最大的礼物之一，让我对这个世界依旧充满好奇。

没意外的话，今年会去一趟美国。不是为了移民，也不是为了炫耀，我很渴望去看看那些全球最顶尖的人在做什么，在想什么。

我的人生不应该只局限在家和办公室之间。不应该只是结婚、生孩子、还房贷。

我不想一直活在"应该"里面。

我也不想我一直活在东亚文化的影响下。

随着和越来越多的朋友交流，我也越来越能感受到我自己身体里的那种冲动。

感恩自己至今还有探索欲。这可能是上天给我最大的礼物之一。

期待我可以勇敢的活出自己，勇敢的追寻我想要的人生。
