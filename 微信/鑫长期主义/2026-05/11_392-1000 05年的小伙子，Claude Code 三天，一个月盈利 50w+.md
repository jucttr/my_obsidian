# 392/1000 05年的小伙子，Claude Code 三天，一个月盈利 50w+


1️⃣ 05 年的小伙子，Claude Code 三天，一个月盈利 50w+

今天参加了生财有术 AI 航海家的深圳线下聚会，报名的是 AI + 产品 / Agent 小组。

小组里确实牛人挺多的，受了不少刺激。

印象最深的案例：一个 05 年的小伙子，零基础，用 Claude Code 三天手搓出一款针对老师群体的班级管理工具，叫「班级宠物园」。核心逻辑是把学生行为积分转化为养宠物的游戏模式。

然后在小红书上卖了近 10 万份，单价 9.9 元，  **一个月盈利 50w+。**

需求来源的思维方式很值得学：看到别人卖得好的产品，但觉得那个产品做得比较一般，于是采取「先抄、再超」的策略。

2️⃣ 用 AI 创造，状态是热爱和玩耍

另一个触动我的点：组内一个小伙伴分享用 AI 创造时，那种基于热爱和玩耍的状态。

**AI 已经大大拓宽了普通人的能力边界，剩下的就是发挥自己的创造力。**

能力的门槛在降低，创造力的权重在提高。

3️⃣ Still early，关键是干起来

用 AI 做出自己产品并且赚钱的人还是少数。我们小组大约 15 人，实现盈利的只有 2 个人。

所以 still early，不用焦虑，关键是干起来。

优质线下活动的价值，就在于看到别人做到的成果和展现出的状态。这种刺激，屏幕前得不到。
