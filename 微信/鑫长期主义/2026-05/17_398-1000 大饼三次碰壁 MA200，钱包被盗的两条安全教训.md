# 398/1000 大饼三次碰壁 MA200，钱包被盗的两条安全教训


1️⃣ 大饼三次碰壁 MA200，当前局势有点危险

大饼三次触碰 MA200 都被压制了，随后选择了向下跌破 7.8w，看上去有点危险。

如果进一步跌破 MA120，这次就有点坑了。因为突破之后磨蹭了快一个月，MA120 本身已经往下移了很多，这会导致摩擦拉大到五六个点。

2️⃣ 粉丝钱包被盗十几万，两条安全教训

今天有个关注我公众号的粉丝朋友私信，说他的钱包被盗了十几万人民币，问还有没有办法追回来。

其实发生这种事，被盗之后能做的很少，大概率追不回来。金额不够大，安全公司也没有动力去帮散户，只能接受现实，复盘总结安全经验。

在现在这种熊市被盗这么多钱，还是非常让人心疼的。和他聊下来，被盗的原因主要是安全意识不够强，认为自己资金量不大，不会被盯上。

两个可能的原因：

• 用 Windows 电脑在桌面上明文保存了助记词。Windows 比较容易下到钓鱼软件， 圈内最好还是用 Mac 加 iPhone。

• 用以前的老钱包参与新项目。DeFi 时代有一条原则叫「一矿一地址」，每个新项目换一个新地址，定期更换，降低单点被攻击的风险。

**安全这件事，「我资金量不大，不会被盯上」是最危险的想法。**  黑客扫的不是人，是漏洞。
