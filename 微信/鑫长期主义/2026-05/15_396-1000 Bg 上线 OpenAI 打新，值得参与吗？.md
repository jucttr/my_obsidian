# 396/1000 Bg 上线 OpenAI 打新，值得参与吗？


1️⃣ Bitget 上线 OpenAI 打新，估值 9000 亿，值得参与吗？

Bitget 又来了一个打新，这次是 OpenAI，估值 9000 亿美金。

上次 SpaceX 的打新，在发行价维持了 20 天才拉盘，最多涨了 20 多个点。这次 OpenAI 还是分两个月分批解锁的，相当于强制持有了一段时间。

估值确实很高，但上一个 SpaceX 毕竟一直没亏过钱，后面如果能等到拉盘也能赚一点。  **如果想配置一些 AI 公司的一级筹码，可以参与一些，但总体是个小机会，仓位不要太大。**

2️⃣ Claude Code 太强大了，大饼助手付费订阅一下子开发好了

大饼助手的付费订阅功能，用 Claude Code 很快就开发好了，运营面板等配套功能也一起做了。目前还在免费体验期，打算 6 月 1 日开始正式收费。

**欢迎关注和反馈，期待市场能给我们一个 3-5 倍赔率的上车机会。**
