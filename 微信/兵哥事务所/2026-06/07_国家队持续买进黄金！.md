# 国家队持续买进黄金！

百年未有之大变局，黄金是见证者。   
  
 中国央行自2024年11月重启购金后，已实现连续19个月增持黄金，且增持速度越来越快。   
  
 2026年1月末+4万盎司   
 2026年2月末+3万盎司   
 2026年3月末+16万盎司   
 2026年4月末+26万盎司   
  
 5月末黄金储备报7,496万盎司（约2,331.52吨），环比增加32万盎司（约9.95吨），创近15个月单月增持新高。   
  
 截至2026年5月末，中国央行官方储备资产合计为38,505.86亿美元，黄金占比仅仅8.9%。   
  
 世界范围内，全球央行黄金储备占比平均水平约为15%，欧洲央行数据显示截至2025年底已升至27%，美国、德国、意大利、法国等国外汇储备中黄金占比更是高达60%-70%。   
  
 在未来相当长时间内，中国央行大概率会持续买黄金。   
  
 2025年中国货物贸易顺差达到1.189万亿美元，历史上首次突破万亿美元大关，如果全部买黄金可购买约7885吨黄金，而全球每年矿产黄金约3700吨。   
  
 为什么我们现在疯狂买黄金？   
  
 第一、中美关系，导致我们对美元的需求在降低，也是在避险集中暴雷。   
  
 第二、截至2026年一季度末，美国联邦债务总额已突破39万亿美元，这是自1946年二战结束后近80年来，美国首次在非战争时期出现负债率超过100%的情况。   
  
 2025财年，美国净利息支出达9704亿美元，高于国防支出的9166亿美元，债务规模扩大 → 利息支出增加 → 利息支出扩大赤字 → 赤字要求更多发债 → 发债供给增加推高收益率 → 更高收益率再推高下一轮利息成本，美债潜在危机越来越严重。   
  
 第三、中国的GDP约为20.65万亿美元。按照美国黄金储备占GDP比例（3.9%） 来推算，中国应有的黄金储备量为8000吨，远高于目前的2331吨。   
  
 如果中美战略竞争中国取胜，人民币必然国际化，我们要提前做一些准备工作。   
  
 黄金恐怕很难大跌，如果有机会可以建仓，百年未有之大变局中，黄金一定是见证者！
