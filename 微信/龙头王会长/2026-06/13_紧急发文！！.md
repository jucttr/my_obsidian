# 紧急发文！！


我们大家好，我是带大家只盯龙头的王会长（先赞后看，不亏只赚）

会长最近发现很多慕名而来的新粉丝朋友们

不知道会长的红旗体系是什么，也不明白咱们的
红旗信号
该怎么用

![](https://mmbiz.qpic.cn/mmbiz_png/sYquqbY5SjP3VvV65kE1vuPezvIDiaTcgOgTmAYtJcic4TaJy2YLEJa40UsKMvBUjX8sSeib1TEqQwGAZHEmT1cDibicrtvMkjXVD3pphhk6fjI0/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)

所以趁着周末有时间，会长就来大详细讲解一下用法

这样大家在后续跟随会长的时候，能够更加清楚明白

会长的
红旗体系
呢？是会长自身经过
十几年的经验
，实战总结而来

能够很好的权衡市场的基本面，技术面，资金情绪面等多层次因素

从而量化出来的一套
能够很好适应A股市场的
完整交易体系
！

我们的红旗体系，模式是以
趋势股+短线龙头
相结合的方式

以长线趋势股为主，以短线为辅，长线短线我们的红旗体系都可以很好的驾驭

一旦基本面，技术面，资金情绪面多层次形成共振，我们的红旗体系就会给我们发出对应的红旗信号

而趋势股的红旗信号，一般以日线级别为主

日线级别的红旗信号
出现得
越多
，往往就代表着接下来的主升浪走势也会
越强

以会长3月份刚带斗牛场的家人，布局过的案例为例

比如我们熟知的兆易创新，在4.14号底部给我们发出了
一根红旗信号
之后

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sYquqbY5SjNDw6oTdgFTPEyctQ7rZV2JNpSI7vEBDOywTgZdsmrdib1CRz7G5yZ2ib7iahhskJibX7hVbZSeWPicwEder8wIB6picuvmZ132W0j50/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1)

后续股价直接沿着我们的擒龙趋势线一路上行，直接开启主升浪，最高涨幅
超过87%

再比如我们熟知的新易盛，当时营长是3.5号斗牛场内和文章中同步给大家公布

当时会长给大家明确说新易盛拥有
2根日线红旗信号

新易盛从3.6号开始，基本上每天文章都给大家聊，
整整给大家聊了一页10篇文章，整整聊了
7页文章

星辰大海

原因无它，就是因为新易盛当时给我们发出了
2根日线级别的红旗信号
而已

![](https://mmbiz.qpic.cn/mmbiz_png/sYquqbY5SjPoRR2hdJIvLWVuS8TLbLicOUxCZCZ7Oj1k4qSs0571PbBewiaTmtkoueUSFpuibPE1O995v2ldpzRWZp9HUM3icOPT6FJBLvG0oUw/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=4)

从红旗信号发出之后，3.5号斗牛场内完成布局，场内也一直
拿到现在

新易盛之后开启主升浪，沿着擒龙趋势线一路上行，之后涨幅超过120%，并且目前趋势还在继续

但是新易盛的
2根日线红旗信号
，依然还不是最强

因为我们当时斗牛场内布局的还有拥有
3根日线红旗信号
的生益科技

![](https://mmbiz.qpic.cn/mmbiz_png/sYquqbY5SjOkpb4TsPYbwEwjeLbW2LNYAicd1k3LcqZU2aE5DAsvQytOibAicaE1EDdyDiaxXg0oQoXCwmcBdHYHwIbRIkazZsDvlh4T7qB1kos/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=5)

从4.9号生益科技给我们发出3根红旗信号之后，生益科技这轮主升浪已经
上涨接近194%
，接近2倍

这就是会长红旗信号的运用方法，日线级别以上往往代表大的主升浪趋势

那有些人会问，那会长我们有没有遇到过周线级别的红旗信号呢？

不是没有，而是很少，从会长给大家每天写文章以来，只带大家遇见过一次
周线级别的红旗信号

那就是我们的长飞光纤

![](https://mmbiz.qpic.cn/mmbiz_png/sYquqbY5SjPCuExlu8bd4zmDD8w6kbzqGqr5PdV3qfZwibm6fCLctvYiaRlHWtk6Hm7eVib5l6dgkWIaC9tooT43ElUQdia33W0fg4PY3aDhpQ0/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=6)

长飞光纤是从2024.9月开始给我们发出的
周线级别的红旗信号

从周线级别的红旗信号发出之后，到现在长飞光纤股价已经
上涨1563%

![](https://mmbiz.qpic.cn/mmbiz_png/sYquqbY5SjPYhW3oQBkibyv99QrdToFPnGQGHsiaTsqPwPSKYGaibzACbPMW003sHMiauXdFg2Gzvd7uDkg3rkREQKyMkJBtdWH5z7Qpp7Zcj1c/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=7)

而会长其实并没有带大家在周线级别红旗发出之后，第一时间布局，
因为那时候会长还没有开始给大家更文章

但是即使我们没有第一时间完成布局，但是会长知道，周线级别的红旗信号绝对没那么
轻易结束

所以我们2025.12月坚定布局的长飞光纤，最后依然带给我们
超过313%的涨幅预期

越往上级别越大，预期越大，红旗信号越多，走势往往预期就越强

但是至于月线级别的红旗信号...

那会长目前也没有见过了，但是级别越高，主升浪持有的时间往往就越长

季度为单位

还在持续
