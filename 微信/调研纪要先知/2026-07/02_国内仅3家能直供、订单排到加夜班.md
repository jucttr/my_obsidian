# 国内仅3家能直供、订单排到加夜班


光连接器——这个过去被当作「标准件、后端件、手搓活」的环节，正在被CPO抬到台前：从800G到1.6T再到CPO，光互联每升一代，接口的密度、精度与价值量就水涨船高，「小接口」正演变成量价齐飞的确定性通胀环节。产品形态一路狂奔——从单芯的LC / SC，到覆盖8 / 12 / 16 / 24芯的MPO / MTP，再到体积只有标准件三分之一的超小型VSFF连接器；而随着CPO临近量产，光纤到芯片（fiber-to-PIC）的精密耦合成了整条链路的卡点，急需供应商拿出量产方案。康宁在首尔重新介绍的玻璃桥方案瞬间引爆全场，把耦合路线之争推上风口——但这是玻璃、金属、传统FAU多路线并行，胜负要看量产节奏而非技术淘汰，市场一定程度上夸大了玻璃桥的落地速度与冲击。更关键的是供给端：能对海外头部CSP做MPO直供的国内厂商只有约3家，部分头部产线订单已饱满到加开夜班、并由大客户锁定上游核心料——量在涨、价在涨、供给还紧，这个环节的能见度，正被CPO一步步顶高。

产业信息，先看这里

①  800G→1.6T→CPO，接口密度水涨船高——「小接口」正被抬成量价齐飞的通胀环节：

逻辑的起点很朴素：光模块速率每升一代，单位面积要塞进的光纤就更多、连接的精度要求就更高。于是连接器从最早单芯的LC / SC，一路演进到覆盖8到24芯甚至更高的MPO / MTP，核心的插芯部件要在微米级把多根光纤的孔位、导针、间距与端面研磨精度全部做到位，直接决定插损与可靠性。速率越高、密度越大，这个环节的价值量就越往上走。它不像光芯片那样是强通胀，但「量价提升＋部分核心料供应偏紧」的通胀逻辑很扎实，是AI算力扩张里一个容易被低估的确定性环节。

②  康宁玻璃桥引爆全场——但这是多路线并行，胜负看量产节奏、不看技术淘汰：

真正把市场点着的是耦合环节。CPO要把很粗的光纤光斑精密耦合进硅光芯片里极小的波导——像把一根粗水管接到细水管上，容差极小，是整条链路临近量产时最急的卡点。康宁在首尔重新介绍的玻璃桥（离子交换玻璃波导、边耦合、被动对准、可插拔）瞬间引爆关注；与之并行的还有三扣的金属MPC方案（面发射＋90度微镜）以及不断迭代的可拆卸FAU。关键在于：这几条路线的性能差异并非天壤之别，客户因CPO上量非常着急，谁先做出工程化落地、跑通量产、把良率拉到位，谁就更可能成为主流——是量产节奏说了算，不是技术淘汰。

③  市场夸大了玻璃桥的冲击——传统FAU不会被一家独大替代，MPO / 光纤反而受益：

围绕玻璃桥有一种极端说法：康宁一家独大、替代掉现有FAU市场。这个判断被高估了。传统固定式FAU在密度、速率要求没那么极致的场景里，工艺成熟、成本可控、供应链完善，仍是性价比主力，未来依旧占大头份额；玻璃桥、金属MPC这些新方案，重点是去吃CPO这类增量市场。更重要的是，这些方案本质只解决了fiber-to-PIC这一端的耦合，MPO、保偏光纤、布线等连接环节依旧是刚需，CPO / NPO演进反而让链路更复杂、密度更高、接口更小型化——对MPO整条赛道是受益而非伤害。

④  国内能直供的只有3家、订单排到加夜班——供给稀缺＋CSP锁料，确定性最强：

如果说前面是弹性，供给端就是确定性。能对海外头部CSP做MPO直供的国内厂商只有约3家，是个天然稀缺的格局。需求侧的信号也很直接：部分头部产线今年二季度以来订单饱满，已经加开夜班、并规划扩产线；而且由大客户直接锁定上游的光纤与MT插芯等核心料，哪怕上游成本上涨，单件盈利也不受影响。再叠加连接器本身仍是偏「手搓」的制造，谁能把自动化程度提上去，谁的利润率就更有弹性。稀缺供给＋锁料＋自动化红利。

一、路线之争：玻璃 / 金属 / FAU三条路线并行赛跑
