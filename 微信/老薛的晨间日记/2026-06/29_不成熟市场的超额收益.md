昨天上午参与 "金一二" 线下活动，多个分享嘉宾轮流分享，收获很多：

1、@黎明、@温虾米 等多位嘉宾提及他们过往抓住的机会，无一例外会提及： 信息渠道、圈子 。

有的是靠早年的微博，有的是靠群里朋友提及，顺藤摸瓜找到属于自己的“不成熟市场的超额收益”。

不仅是他们，我自己人生命运的转折其实也是靠信息入口的改变来实现的。

所以， 想变好甚至改运，先判断下自己的信息源是否足够的多、质量足够的好、以及为这些投入了多少金钱资源？

【有奖招募】：如果你有好的圈子、社群，欢迎推荐给我，如果我因为这个付费了，有你邀请链接的我会用你的，没邀请链接且我因为你购买了，我会给你红包。

2、@金马哥 提及了常用的 4 个 AI agent：

龙虾、爱马仕、claude code、codex。

爱马仕还没用过，打算研究下。

@金马哥 对 AI 的研究是很前沿的，上述是普通人接触的最顶的几个了，自己是否有了解、接触？

AI 是生产工具、是先进的生产力，这个不能落后。

3、@温虾米 给我最大的触动就是： 不成熟市场的特征&超额收益 。

![](https://mmbiz.qpic.cn/mmbiz_png/nefNajZywictiafLs7gcANALzOsQUXmgzJhYCDexzGEuvNgtlfHricZu1TYAYhhsianVm9HIng87ibCs09tX2rIjCHBiakHugiasDrI8VqdVwiby2bU/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)

给我的触动：

市场不成熟，既是挑战又是机遇。挑战是各种基建不成熟、各种乱象，机遇是： 会给普通人带来很多超额收益 。

当聪明人、机构大玩家入场，一方面乱象少了，另一方面对普通人的机会通道也关闭了。

最后： 看清自身 x 匹配策略 x 不断学习=活着穿越周期

4、@风摇 提及：

好多 app 不提供 api 接口，但可以通过 claude code 等反向寻找线索，这个有意思…

5、@小鑫 分享的：

重要的不是买在最低点，而是机会来临时有钱、有计划、有心态。

6、最后金豆子分享时候不得不赶飞机，错过了，但依旧是全场最牛的那一个死多头，哈哈哈。

总之，昨天上午收获很多。
