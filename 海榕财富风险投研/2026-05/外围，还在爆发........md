# 外围，还在爆发.......


大家好，我是海榕君。

科技股投资看纳斯达克
，
周五晚上，美股科技股继续大涨，纳斯达
上涨2.34%。 CPU巨头英特尔上涨13.96%，存储三巨头之一，
美光科技上涨15.49%，谷歌再破前高，市值站上4.86万亿美元。

![](https://mmbiz.qpic.cn/mmbiz_png/CD0Ziab37FHAz5R9q20pKn9u5IoIq0Hia2jFs2URmJHEscyqNr8TmgibLic4Lh8CUb4spHWEDu6Yk6xRaNxAH2a4dEJT9DZctzgbaOIW8VS2dA4/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)

这波美股科技股上涨的核心逻辑是，
美国有一家AI大模型公司
Anthropic，突然找到商业模式，让市场看到AI跑通了。

在今年3月的时候，它的
ARR（年化运行收入）还在
300亿美元营收，4月份直接增长到
440亿美元，
Anthropic
成
为全球增长最快的公司。

Anthropic的
毛利率很高，非常赚钱。今年3月份的
毛利率还只有38%，4月份直接增至70%以上。并且客户都是高富帅，财富 10 强中已有 8 家是 Claude 客户，包括谷歌和苹果的程序员都在用他们家的产品。

这等于是，市场突然看到，AI已经找到 稳定变现的商业模式，度过可不确定的0到1后，开始
面向专业领域提高生产力，进行1到100的复制。

Claude Code 最近又进入法务、金融、咨询、客服、营销、研发等更稳定的工作链条，这些TO B客户付费意愿强，美股市场直接给出线性类推，把
Anthropic的估值推向
1.2万亿美元的估值。

.....

还有一些资深投资者，对
Anthropic的爆发，产生疑问。

AI确实在逐渐改变生活，但几百亿美元的纯AI付费需求，带来万亿美元的AI基建，再撬动数十万亿美元AI产业链的股票市值涨幅， 几乎千倍的杠杆了。

就像当2000年的互联网行业，大家都知道前景很好，有一些已经找到商业模式，但是如果估值很离谱，还是会进入估值杀，一些龙头公司的估值，10年后才拉回来。

还有类似于2021年的锂电新能源行业，当时宁德的估值达到2030年，后期股价跌了3年，最近宁德才破了前高。

还是遵循前期的交易规则， 底部看基本面， 顶部看技术面 。涨的多的，就看线、看图就对了。

如果低于预期，又可以解读为需要降息，还是利好。

3.
世纪华通老板减持3%

例如，最近我准备买一个电子反光三脚架，我真不想在淘宝选择，直接交给AI更省心。

阿里未来，更应该在TO B编程发力，阿里本来就是擅长做TO B， 在移动互联网时代的劣势，反而成为在AI时代的优势。
