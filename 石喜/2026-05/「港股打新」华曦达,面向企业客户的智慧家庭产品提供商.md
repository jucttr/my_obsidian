# 「港股打新」华曦达,面向企业客户的智慧家庭产品提供商


# **Part1** 公司简介及业绩情况

**深圳市华曦达科技股份有限公司**  是面向企业客户的「智慧家庭产品」提供商，致力通过智能技术提升家庭应用体验。

> 智慧家庭产品指一套连接及管理全屋智能设备的综合家庭生态系统，可实现全屋网络覆盖和设备交互。

公司提供的智慧家庭产品包括硬件及软件产品。公司的收益主要来自销售硬件产品，即数字视讯设备及网络通信设备。

公司是面向  **企业客户**  的智慧家庭产品提供商，以客户品牌为企业客户开发并销售数字视讯设备及网络通信设备，并提供系统平台及服务。

公司已为全球超过  **80个国家及地区**  的  **300余名客户**  提供服务，客户主要为  **电信运营商**  ，再由电信运营商负责把产品卖给终端用户。

换句话说，华曦达就是给全球家庭提供“上网、看电视、智能家居”的硬件设备厂商，全部安装、使用在家庭环境里。

在面向企业客户的全球智慧家庭产品市场中，按2025年收益计，公司是  **全球第七大**  提供商，也是中国  **大陆第三大**  提供商，市场份额为  **3.3%。**

- **软件**

公司的系统平台包含Cedar（家庭AI智能体），以及XMediaTV（流媒体平台）和XHome（家庭设备管控平台）。Cedar作为认知决策核心，可以利用Gemini对数据进行分析处理，实现高精度的意图识别，并通过XMediaTV和XHome，下达情景感知行动指令。

- **硬件**

网络通信设备包含Wi-Fi路由器、光网络终端、线缆调制解调器，为用户构建家庭高速网络连接、实现全屋网络稳定覆盖。数字视讯设备包含流媒体终端、投影仪、摄像头及AI音箱。此外，截至最后可行日期，我们有机器人、AI眼镜、AI相框及AI算力中心等其他在研AI驱动产品，可为用户提供娱乐及陪护。

- **开放生态**

我们的家庭生态是基于Matter协议的开放生态，能够实现跨生态、跨品牌的设备互联互通，将更为广泛的各类智慧家庭设备接入到我们的单一管理与自动化框架下，实现了无边界的设备拓展。

整体上看，公司近几年的业绩一般般。

# **Part3** 综合分析

**华曦达**  是面向企业客户的「智慧家庭产品」提供商，公司选把产品卖给电信运营商，再由电信运营商负责把产品卖给终端用户（家庭）。

公司的收益来自国内及海外市场（包括亚洲、欧洲、美洲），2025年海外收入占比为  **90.3%，**  海外市场是公司的主要收入来源。

全球企业智慧家庭产品市场竞争格局相对分散。按2025年收入计，十大市场参与者占总市场份额约  **53.9%。**  在全球企业智慧家庭产品市场中，按2025年收益计，公司是  **全球第七大**  提供商，也是中国  **大陆第三大**  提供商。

![](https://mmbiz.qpic.cn/mmbiz_png/lE7mzZGxFSSK3KGD36QGZ572l2n26Viab79PEXCagk54yobNYPXb1ic1loLDGXtfSJKiaCE7n2Voky8BER6QWBnubWwianUiaWKbKOZSibCnCaQQU/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)

全球企业智慧家庭产品市场规模从2021年的  **77亿美元**  增长至2025年的  **148亿美元**  ，2021年至2025年期间的复合年增长率为  **17.7%。**  未来，全球企业智慧家庭产品市场规模将进一步扩张，并预计于2030年达到  **354亿美元**  ，2025年至2030年期间的复合年增长率为  **19.1%。**

公司的可比公司有一家深圳上市公司创维数字，两家公司2025年的业绩指标如下表：   
![](https://mmbiz.qpic.cn/mmbiz_png/lE7mzZGxFSSfRdI5ND6VjgAMHlWmbSLoouTceuzK1xNvrTudMSV5afIiaQO3gy8CVnEibd7dl5GQIwtdALJD6e5uDBloHia2SfeqVibxo2ublBs/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=3)

创维数字的收入和利润从2022年起连年下滑，2022年收入和利润分别为120亿和8.23亿，2025年下滑到88亿和1.7亿。且创维数字2025年各项指标都不如华曦达（除了收入高点）。

华曦达的市值是60亿人民币左右，创维数字的市值是146亿人同币，是华曦达的2.4倍，但利润还不如华曦达，这么看的话，  **华曦达的估值还行**  。

不过，华曦达的近几年的业绩本身也不怎么样，除了收入增长较快之外，其它指标一般或者下滑，这说明  **这个行业本身不太好，参与者不太赚钱**  。

看完了基本情况，再看看发行情况。

公司发行价为  **32.8港元**  ，发行后市值为  **68.73亿港元**  ，本次募资额为  **6.3**  亿港元，其中公开募资额为  **0.63亿**  港元。100股为一手，每手金额为  **3280港元**  ，总共  **19208手**  。

本次发行  **没有基石、没有绿鞋**  。

结论：

- **公司是面向企业客户的「智慧家庭产品」提供商，主要业务在国外，是全球第七大提供商，市场份额3.3%，预计未来4年行业的复合增长率为19.1%。行业不是热点，未来增长空间还行。**
- **公司近几年业绩一般，收入增长率还行，但利润增长率低于收入增长率，原因是毛利率和净利率下滑，行业可以公司也是一样的情况，市场参与者不太赚钱，也就是这，这是一个一般的行业。**
- **公开货量仅0.63亿，货量少，没有基石和绿鞋，是减分项。**

**一句话总结就是，公司行业一般，不是热点，业务没多大技术含量，行业毛利率低，行业参与者不赚钱。公司业绩一般，未来想象空间也一般。总之，这是一家基本面一般的公司。**

**云英谷科技**  主营业务为「智能手机AMOLED显示驱动芯片」，在大陆市场份额12.4%，排名第三。公司所在行业竞争激烈，导致公司毛利率低且亏损严重。本次发行基石名气一般，没有绿鞋。总之，  **这是一家基本面一般的公司**  。

**深演智能**  的细分行业是「中国营销和销售决策AI应用市场」，粘上点AI这个热点概念。公司的市场份额2.6%，排名第一，但市场极度分散。公司近几年业绩比较差，收入、净利润、毛利率和净利率等指标全线下滑。预计行业未来4年高速增长（复合增长率36.5%）。公开货量公0.5亿，且本次发行没有基石和绿鞋。总之，  **这也是一家基本面一般的公司，好在粘上点热点**  。

**华曦达**  我上面说了，  **也是一家基本面一般的公司。**

如果非要给三家公司的基本面排个序的话，我认为是  **深演智能=云英谷科技>华曦达**  。

4月初到现在，新股热度高涨，涨幅100%都是小涨，特别是胜宏科技、曦智科技和剂泰科技三支货多大肉签，直接把情绪拉满。

不过，这样高涨的情绪明显不正常，这不，今天上市的拓璞数控和驭热科技的情绪急转直下，且驭势科技还破发了（基本面差也是因素之一）。

不但新股情绪下降，次新股情绪也在下降，近期上市的新股和首日比都有明显下跌（包括曦智和剂泰）。

总之就是情绪面回归理性了，以前是无脑打，现在要看看基本面了。

本轮这三支，如果单看基本面的话，都没啥意思，好在目前的情绪面仅仅是下降，而不是消失，所以我认为如果考虑情绪面的话，还是值得参与的。

从参与度排序来看，我认为是  **深演智能=云英谷科技>华曦达。**

如果你风险承受能力低，可以把华曦达排除或者少量认购，重点参与另外两个。

很遗憾，由于资金正被丹诺医药冻结着，我目前看不到实时的孖展情况，且目前是情绪面从高涨到回归理性的时期，我不知道会有多少人放弃认购，我现在没办法预测最终的孖展数据，所以我不能结合孖展情况来给出具体的认购策略以及中签率预测。

**有没有可能破发？**  当然有可能了，不过破发并不是什么可怕的事情，遇到破发很正常，接受就完了，你是要算总账的，不必纠结于少数几次的亏损。

我已经强调多次了，  **港股打新是一个「胜率&赔率」站在你这边的概率游戏**  。只要概率&赔率合适就应该下注。

我大胆预测，深演智能和云英谷科技的  **胜率**  明显>50%，  **赔率**  明显>1（我定义赔率=涨幅÷跌幅）。

所以，  **这三支（或者前两只）我大概率会融资打满，不过，最终怎么打还要结合今天晚上的孖展情况再定。**
